# Атлас Халлоунеста

Полевой справочник по The Unofficial Hollow Knight RPG. В зале с лавочками собраны бестиарий, экипировка, состояния и памятка правил.

[Открыть сайт](https://thwwins96.github.io/hallownest-atlas/)

## Общий архив

Сайт читает архив из Supabase. Сохранённые правки становятся доступны всем посетителям сразу после записи и появляются в открытых вкладках в течение нескольких секунд. Исходные карточки в папке data служат резервом на случай недоступности базы.

ГМ открывает режим редактора на сайте и вводит пароль. В Supabase хранится только хеш пароля. Посетители читают архив без входа. Сохранение проверяет версию записей, чтобы один ГМ случайно не затёр правки другого. В редакторе доступны добавление, изменение, удаление и перенос архива в JSON.

Схема базы находится в supabase/hallownest.sql. Для отдельной установки нужно настроить URL проекта и открытый ключ в archive-api.js, зарегистрировать хеш пароля ГМа в закрытой схеме и загрузить исходные записи.

The Unofficial Hollow Knight RPG — RUS v.1.7, «Записки Дуэлянта», «Журнал Скальда» и памятка начальной экипировки. Фанатский некоммерческий проект.
